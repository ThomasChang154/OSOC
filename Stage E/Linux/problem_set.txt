第一行可能有点棘手， # 在 Bash 中表示注释，

系统看到这个组合，就知道后面跟着的是解释器的路径。

1.10
写一段命令来从 /sys 中获取笔记本的电量信息，或者台式机 CPU 的温度。
答：
笔记本的电量信息存放在 /sys/class/power_supply 目录下，执行：
cd /sys/class/power_supply 
之后执行 ls 发现有 AC1 和 BAT1 ，我们查看 BAT1 的情况：
cd BAT1
cat status
发现输出为 FULL ，可知 BAT1 为已充满状态。此外，执行：
cat capacity
可以获知电量百分比，例如 100 为 100% 满电状态。

2.2
编写两个 bash 函数 marco 和 polo 执行下面的操作。
每当你执行 marco 时，当前的工作目录应当以某种形式保存，
当执行 polo 时，无论现在处在什么目录下，都应当 cd 回到当时执行 marco 的目录。 
为了方便 debug，你可以把代码写在单独的文件 marco.sh 中，
并通过 source marco.sh 命令（父进程中执行），重新加载函数。
答：
如果写成两个独立的脚本，则：
marco.sh 的脚本代码如下：
-----------------------------------------------------------------
#!/bin/bash

path=$(pwd)
echo "${path}" > /tmp/dir_rec.txt
-----------------------------------------------------------------
polo.sh 的脚本代码如下：
-----------------------------------------------------------------
#!/bin/bash

path=$(cat /tmp/dir_rec.txt)
cd "${path}"
-----------------------------------------------------------------
如果写成一个完整的脚本，则：
-----------------------------------------------------------------
#!/bin/bash

function polo()
{
	local record=$(cat /tmp/dir_rec.txt)
	if [ "${record}" == "" ]; then
		echo "You should execute function marco first."
		exit 1
	else
		cd "${record}"
		echo "We have changed our directory to ${record}."
	fi
}

function marco()
{
	echo "$(pwd)" > /tmp/dir_rec.txt
	local path=$(pwd)
	echo "We are at ${path} now." 
}

# If you want to save the directory where you are, 
# please execute: source marcopolo.sh 0
# If you want to change the directory where you are,
# to the latest saved directory, 
# please execute: source marcopolo.sh 1

if [ "${1}" -eq "0" ]; then
	marco
elif [ "${1}" -eq "1" ]; then
	polo
fi
-----------------------------------------------------------------

2.3
假设您有一个命令，它很少出错。因此为了在出错时能够对其进行调试，
需要花费大量的时间重现错误并捕获输出。 
编写一段 bash 脚本，运行如下的脚本直到它出错，
将它的标准输出和标准错误流记录到文件，并在最后输出所有内容。
加分项：报告脚本在失败前共运行了多少次。
-----------------------------------------------------------------
#!/usr/bin/env bash

 n=$(( RANDOM % 100 ))

 if [[ n -eq 42 ]]; then
    echo "Something went wrong"
    >&2 echo "The error was using magic numbers"
    exit 1
 fi

 echo "Everything went according to plan"
-----------------------------------------------------------------
答：
将代码修改成如下形式，引入 until 循环记录执行次数，即可知失败前一共运行的次数：
-----------------------------------------------------------------
#!/usr/bin/env bash

n=$(( RANDOM % 100 ))
i=1

until [[ n -eq 42 ]]
do
	n=$(( RANDOM % 100 ))
	echo "${i} Everything went according to plan"
	i=$((i+1))
done

echo "${i} Something went wrong"
>&2 echo "The error was using magic numbers"
exit 1
-----------------------------------------------------------------

2.4
本节课我们讲解的 find 命令中的 -exec 参数非常强大，
它可以对我们查找的文件进行操作。但是，如果我们要对所有文件进行操作呢？
例如创建一个 zip 压缩文件？我们已经知道，命令行可以从参数或标准输入接受输入。
在用管道连接命令时，我们将标准输出和标准输入连接起来，
但是有些命令，例如 tar 则需要从参数接受输入。
这里我们可以使用 xargs 命令，它可以使用标准输入中的内容作为参数。
例如 ls | xargs rm 会删除当前目录中的所有文件。
您的任务是编写一个命令，它可以递归地查找文件夹中所有的 HTML 文件，
并将它们压缩成 tar.gz 文件。
注意，即使文件名中包含空格，您的命令也应该能够正确执行。
提示，使用 find 命令的 -print0 选项配合 xargs 命令的 -0 选项。
答：
执行下面的命令即可：
find . -iname "*.html" -print0 | xargs -0 tar -czvf html_all.tar.gz
此处需要说明的是：
选项 -iname 表示按不区分大小写的名称进行查找；
选项 -print0 表示以“\0”为分隔标志进行分隔；
选项 -0 表示以“\0”为拆分标志进行拆分；
选项 -c 表示创建压缩包；
选项 -z 表示压缩算法为 gzip ；
选项 -v 表示列出正在被处理的项目；
选项 -f 表示创建压缩包的自定义名称。

2.5
（进阶）编写一个命令或脚本递归的查找文件夹中最近修改的文件。
更通用的做法，你可以按照最近的修改时间列出文件吗？
答：
执行下面的命令即可：
find . -mtime -3 -print0 | xargs -0 ls -lhtd
此处需要说明的是：
选项 -d 表示遇到目录不列出目录的内容，仅列出目录本身。
